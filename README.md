Личный трекер настроения. Одна запись в день, статистика, тёмная тема.

## Возможности

- Ежедневная запись настроения (1-5) с заметкой
- Редактирование и удаление записей
- Статистика: серия, среднее, счётчики
- Тёмная тема
- Данные хранятся локально (localStorage)
- Адаптив под мобильные

## Стек

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Zustand (стейт + persist)
- date-fns
- Lucide React
